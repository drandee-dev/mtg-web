Recommendations
Two-step: EDHREC data + Claude 1-line reasoning per card
EXISTING + Claude
Step 1 — EDHREC cards
POST /api/deck/recommend
Returns categorized card lists with raw synergy scores from EDHREC. Show immediately — no waiting on Claude.
Step 2 — Claude reasoning
POST /api/deck/ai/explain
Pass top-N card names from Step 1. Claude returns a 1-line "why this fits" per card. Lazy-load — show synergy % while reasoning streams in.
ai/explain request
{
  decklist: string,
  format: string,
  card_names: string[],  // top 8-12
  bracket?: number
}
ai/explain response
{
  explanations: {
    "Sol Ring": "Ramp staple; your curve...",
    "Eternal Witness": "Recursion for your...",
    // ...
  }
}

Upgrade Path
Budget swaps (existing) + Power upgrades (new Claude endpoint)
EXISTING (budget) NEW (power)
Budget swaps (existing)
POST /api/deck/budget-swaps
Finds cheaper functional equivalents using price data. Pass threshold (e.g. $10) to define "expensive".
Power upgrades (new)
POST /api/deck/ai/upgrades
Claude identifies the highest-impact upgrades regardless of budget — the cards that most improve the strategy at any price.
ai/upgrades request
{
  decklist: string,
  format: string,
  commander?: string,
  bracket?: number,
  mode: "power" | "budget"
}
ai/upgrades response
{
  upgrades: [{
    replaces: string,
    replacement: string,
    reason: string,
    price_usd?: number
  }]
}

Draw Odds
Client-side hypergeometric calculation — no API call needed
CLIENT-SIDE
Formula
// Hypergeometric distribution
// P(X >= 1) = 1 - P(X = 0)
P = 1 - C(N-K, n) / C(N, n)

N = deck_size (e.g. 99)
K = copies in deck
n = cards seen (hand + draws)
Inputs
Copies in deckauto from decklist
Hand size7 (editable)
Draw by turneditable
Deck sizeauto from decklist
